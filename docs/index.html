Install in Codex

codex plugin marketplace add viames/numbers-native
codex plugin add numbers-native@viames-numbers

Start a new local task and run setup. Requires Apple Numbers, Node.js 22+ and Automation permission on a logged-in Mac. Compatible MCP hosts can use the macOS MCPB bundle; install the Codex plugin to include its skills.

Native documents and charts

38 tools for tables, formulas and formatting, custom prototypes and eleven verified chart profiles with guided source updates.

Changes you can inspect

Preview related edits, check native results, import typed CSV/TSV records by key, and create before/after PDF and PNG previews.

Keep the whole document

Back up, restore and move native documents together with their chart metadata. No Excel conversion, GUI driver or extra API key.

Clear boundaries

This preview was verified on one Mac with Numbers 14.5. Other versions are not certified. Numbers does not expose arbitrary chart type, series, axis or internal-title editing; template-linked charts preserve known native links. Operations can partially apply and have no automatic rollback. Imports are bounded to a 2,000-cell resulting table.

The bridge has no telemetry or direct network upload. Tool data still passes through the host and its model under the host's policies. Read the privacy policy and verification report.
