Numbers Native

Privacy

Maintained by Viames Marino. Last updated: 18 October 2026.

Numbers Native runs locally on macOS. It reads or changes explicitly selected Numbers documents and returns requested values, formulas, document metadata and previews to the Codex/MCP host. That host may send them to its model provider under its own policies. Local automation does not guarantee that all spreadsheet data stays on the device.

The bridge has no telemetry, account system, network listener or direct network upload. It requires no additional API key. Numbers can save and synchronize documents through locations and services chosen by the user, including iCloud; these remain outside the plugin's control.

Native documents may be autosaved before explicit saving. Chart mappings persist in adjacent JSON companions containing paths, source ranges and structural fingerprints, not cell matrices or formula history. Backups and previews are created at requested paths. CSV/TSV sources are read locally and hashed for preview consistency; the bridge keeps no input archive or content history. The host can log tool requests and results independently.

Default file access uses explicit paths/document IDs; users can restrict paths with NUMBERS_NATIVE_ALLOWED_ROOTS. Automation permission is required. Accessibility, UI scripting and clipboard automation are not used.

This static website has no application analytics, tracking scripts, forms or cookies added by the project. It is hosted on GitHub Pages and may load example media from GitHub. GitHub's own infrastructure policies apply.

Support: GitHub issues. Do not post private spreadsheets, credentials or personal data. Read the full packaged policy.
