# Changelog

## 0.5.0 — 2026-10-18

First public preview by Viames Marino, released under MIT.

- 38 native MCP tools and two Codex skills.
- Guarded multi-table edits with preview, revision checks and final native readback.
- Native-result checks for required values, uniqueness, formulas, bounds, equality and balances.
- Explicit typed UTF-8 CSV/TSV append and exact-key upsert, with protected formulas.
- Compatible base-format preservation, custom native prototypes and guided chart updates.
- Eleven template-linked chart profiles verified on Numbers 14.5.
- Paired document/metadata backup, new-path restore and verified move/rename.
- Native PDFKit PDF/PNG previews and local compatibility diagnostics.
- Codex marketplace ZIP, standalone plugin ZIP and macOS MCP bundle.

Verified on one physical Mac. Native operations are not transactions and errors may follow partial changes. Arbitrary chart type/series/style editing, pivot creation, conditional rules and other unexposed Numbers features remain unsupported. See the capability matrix and verification report.
